# Python Cafe Ordering System

A simple console-based Cafe Ordering System developed using Python.

## Features

* Displays a cafe menu with prices
* Allows users to order multiple items
* Calculates total bill automatically
* Generates an order receipt
* Handles invalid inputs using exception handling

## Concepts Used

* Dictionaries
* Lists
* Loops
* Conditional Statements
* Exception Handling
* User Input Handling

## Menu Items

* Coffee
* Tea
* Sandwich
* Pasta
* Burger

## How to Run

```bash
python cafe.py
```

## Sample Output

```text

Here is the menu:
----------------------------
```
